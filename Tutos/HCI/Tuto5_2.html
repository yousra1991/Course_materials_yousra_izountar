HCI Tutorial 5.2: Evaluation of HCI: Usability and User Testing

Questionnaires · Perception and 5-second tests · Observation · Heatmaps · Interviews · A/B testing

Objectives

By the end of this tutorial, you should be able to:

  • Explain what to evaluate and distinguish utility, usability and usage (ISO 9241-11).
  • Design questionnaires (Likert, SUS), a perception test and a five-second test.
  • Plan and analyse a usability test with observation (scenario, measures, number of users).
  • Read a heatmap, run an A/B test and interview users, then combine all the results into a decision.

Context · Testing the university website with users

The ergonomists inspected the University of Algiers 1 website (Tutorial 5.1) and the designers fixed the main problems. Now the team must test the website with real users: students such as Sara, teachers, and administrative staff. You prepare and analyse the tests. A few weeks later, the first version is live and the team studies how it is used.
