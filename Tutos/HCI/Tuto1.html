HCI Tutorial 1: UI vs UX and Types of Adaptation

Exercise 1: How the UI affects the UX · Exercise 2: Types of adaptation

Objectives

By the end of this tutorial, you should be able to:

  • Distinguish UI (what users see and touch) from UX (the overall experience) and explain how interface choices affect the experience.
  • Identify which design principle is violated in a situation (visibility, feedback, consistency, error prevention, accessibility).
  • Propose a realistic fix for a UI problem.
  • Identify the source of adaptation of an interface: context, task, user characteristics or technical constraints.
  • Distinguish adaptable from adaptive systems and say what is adapted.
  • Apply the 4-step adaptation method and check its risks.

Quick reminder

UI vs UX
UI: layout, colours, typography, icons, buttons, feedback.
UX: ease of use, efficiency, errors, emotions, satisfaction.

VisibilityFeedbackConsistencyError preventionAccessibility
Adaptation
4 sources: context, task, user characteristics, technical constraints.
Adaptable: the user changes the settings. Adaptive: the system adapts automatically.
What can be adapted: content, presentation, navigation, modality, behaviour.

Exercise 1 · How the UI affects the UX

1.1 – Good-looking is not the same as good experience

Situation. An online shop has a very attractive design, but customers cannot find the delivery costs and abandon their purchases.
a) What does this situation show about the relation between UI and UX?
b) Propose two UI changes that would improve the experience.
🔒 Solution – teachers only

1.2 – Which principle is violated?

For each situation, name the violated principle and the main consequence for the user.

#Situation
aA pay button is light grey on white with 9 px text.
bAfter clicking « Submit », nothing changes for 5 seconds.
c« Save » is a floppy-disk icon on one screen and a tick on another.
dA student uploads a 20 MB file and the page shows no progress for a minute.
eDates appear as 12/10/2026 on one page and as Oct 14th, 2026 on another.
🔒 Solution – teachers only

1.3 – Propose a fix

For each problem, propose a concrete correction and name the principle it restores.

#Problem
aA form displays: Error 500: NullPointerException at RegService.java:42.
bA Delete registration button looks identical to Save, sits right next to it, and works without confirmation.
cA toolbar shows only icons (trash, gear, upload) and users misunderstand them.
dA button is labelled « Go ».
eTouch targets are only 8 px high.
fThe password rules are only shown after the form has been submitted.
🔒 Solution – teachers only

Exercise 2 · Types of adaptation

2.1 – Source of adaptation

For each scenario, say which source drives the adaptation: context, task, user characteristics or technical constraints. Justify in one sentence.

#Scenario
aA video player lowers its quality when the student's internet connection is slow.
bA student revises at night and the platform switches to dark mode after 8 pm.
cA mobile banking app hides the balance by default when the user is outdoors, in a public queue.
dAn app uses a step-by-step flow with confirmations only for critical, rarely done actions (e.g. a money transfer).
eA student with dyslexia can enable a dyslexia-friendly font and wider line spacing.
fWhen the campus Wi-Fi is overloaded, the portal serves a lighter version of its pages.
🔒 Solution – teachers only

2.2 – Adaptable or adaptive? What is adapted?

For each scenario, say who triggers the adaptation (adaptable = user, adaptive = system) and what is adapted (content, presentation, navigation, modality, behaviour).

#Scenario
aA user chooses Arabic or French in the settings and the interface switches its layout direction.
bThe platform switches to dark mode after 8 pm.
cOn a limited data pack, a platform replaces a 120 MB lecture video by a text version and a PDF.
dThe campus portal serves a lighter version of its pages when the Wi-Fi is overloaded.
🔒 Solution – teachers only

a) Put the four steps of the adaptation decision method in order.
b) Apply them to this case.
c) Which risk is the most serious? Propose a safer design.
