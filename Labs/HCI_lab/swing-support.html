02A Swing window: JFrame

Every window is a class that extends JFrame: the constructor builds it, main shows it.

Skeleton of every Swing class

Lab 1.1all labs

The structure to start each exercise from.

import javax.swing.*;
import java.awt.*;

public class MyWindow extends JFrame {

    public MyWindow() {
        setTitle("My window");
        setSize(500, 300);
        setLocationRelativeTo(null);
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        // 1. create the components   2. add them   3. attach the listeners
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> new MyWindow().setVisible(true));
    }
}

SwingUtilities.invokeLater starts the interface on the Swing thread; setVisible(true) always comes last.

JFrame

Lab 1.1Lab 1.2Lab 3.1

The main window: title bar, borders, close button, and a content area.

setTitle("…")Text of the title bar.
setSize(w, h)Size in pixels.
pack()Size adapted to the content (instead of setSize).
setLocationRelativeTo(null)Centres the window on the screen.
setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE)Closing the window stops the program.
setDefaultCloseOperation(JFrame.DO_NOTHING_ON_CLOSE)You decide what happens on ✕ (to ask a confirmation, chapter 08).
setLayout(…) / add(c)Choose the layout / add a component.
setJMenuBar(bar)Attach a menu bar (chapter 07).
setVisible(true)Show the window.

03Containers and layout managers

A layout manager decides where each component goes and how big it is. Build small panels, each with its own layout, then put the panels in the window.

FlowLayout

Lab 1.1Lab 1.2Lab 2.1

Components in a row, one after the other; a new line when there is no more room. For a row of buttons, a label followed by its options.

JPanel row = new JPanel(new FlowLayout(FlowLayout.LEFT)); // or CENTER (default), RIGHT
row.add(b1);
row.add(b2);

Default layout of a JPanel.

GridLayout

Lab 1.2Lab 2.1Lab 3.1

A grid of cells of equal size, filled row by row. Ideal for forms: label | field.

JPanel form = new JPanel(new GridLayout(2, 2, 8, 8));    // rows, columns, gaps
form.add(new JLabel("Name:"));  form.add(new JTextField(12));
form.add(new JLabel("City:"));  form.add(new JTextField(12));

JPanel column = new JPanel(new GridLayout(0, 1, 5, 5));   // 0 rows = as many as needed

With 6 components and 2 rows you get 3 columns: match rows and columns to the number of components.

BorderLayout

Lab 1.2Lab 3.1

Five regions: NORTH, SOUTH, EAST, WEST, CENTER. One component per region; CENTER takes the remaining space.

setLayout(new BorderLayout(10, 10));          // gaps between the regions
add(title, BorderLayout.NORTH);
add(content, BorderLayout.CENTER);            // takes the remaining space
add(status, BorderLayout.SOUTH);

Default layout of a JFrame: every add(c) without a region goes to CENTER and replaces the previous one.

JPanel: nesting panels

Lab 1.2

A container with its own layout. To put several components in one region, put them in a panel first.

JPanel buttons = new JPanel(new FlowLayout(FlowLayout.RIGHT));
buttons.add(new JButton("Cancel"));
buttons.add(new JButton("OK"));               // main action last, on the right
add(buttons, BorderLayout.SOUTH);             // one panel = one region

Draw the window on paper first: which panels, which layout in each? Colour a panel temporarily with setBackground to see its limits.

JScrollPane

Lab 2.1Lab 3.1Lab 3.2

Adds scrollbars around a component that can grow: JTextArea, JList, JTable, JTree.

add(new JScrollPane(area));                    // scrollbars appear when needed

JTabbedPane

Lab 2.1Lab 3.2

Several panels in the same space, one tab each. Used to split a long form or separate kinds of content.

JTabbedPane tabs = new JTabbedPane();
tabs.addTab("General", first);                 // one tab = one panel
tabs.addTab("Options", second);
add(tabs, BorderLayout.CENTER);

JToolBar

Lab 3.2

A bar of buttons for frequent commands, usually at NORTH, each with a tooltip.

JToolBar bar = new JToolBar();
JButton newBtn = new JButton("New");
newBtn.setToolTipText("Create a new item");
bar.add(newBtn);
add(bar, BorderLayout.NORTH);

04Appearance

Colours, fonts, alignment, tooltips and titled borders: what the labs use to match the mock-ups.

Colours, font and alignment

Lab 1.2

Change the background, the text colour, the font style and the alignment of a text.

JLabel header = new JLabel("Header", SwingConstants.CENTER);  // centred text
header.setOpaque(true);                       // a JLabel is transparent by default
header.setBackground(new Color(0x2196F3));     // colour in hexadecimal
header.setForeground(Color.WHITE);             // text colour
header.setFont(header.getFont().deriveFont(Font.BOLD));
panel.setBackground(Color.LIGHT_GRAY);

Without setOpaque(true) the background of a JLabel is not painted.

Tooltip and titled border

Lab 3.1Lab 3.2

A tooltip explains a field or a button on hover; a titled border names a group of components.

code.setToolTipText("6 digits, no spaces");   // shown after about 1 s on hover

JScrollPane box = new JScrollPane(notes);
box.setBorder(BorderFactory.createTitledBorder("Notes"));   // a framed, named group

05Text components

To show a text, type one line, type a hidden text, or type several lines.

JLabel

Lab 1.1all labs

A text the user reads: the label of a field, a result, a status bar.

JLabel hint = new JLabel("Name:");
hint.setText("Full name:");                    // change the displayed text

JTextField

Lab 1.1Lab 1.2Lab 3.1

One line of text typed by the user. Can also show a result that cannot be changed.

JTextField name = new JTextField(15);          // width: 15 columns
String typed = name.getText();                 // read
name.setText("");                              // clear
JTextField result = new JTextField(15);
result.setEditable(false);                     // shown, but cannot be typed in

JPasswordField

Lab 2.1

A hidden input: each character is shown as a dot.

JPasswordField pw = new JPasswordField(15);
String secret = new String(pw.getPassword());  // getPassword() returns a char[]

getText() is deprecated on a password field: use getPassword().

JTextArea

Lab 2.1Lab 3.1

Several lines of text: comments, a summary, a description.

JTextArea comment = new JTextArea(4, 25);      // 4 rows, 25 columns
comment.setLineWrap(true);                     // go to the next line automatically
add(new JScrollPane(comment));                 // never add the bare text area

Swing has no placeholder: leave the area empty or write a starting text.

06Buttons and choice components

Choose the component from the kind of data: an action, yes / no, one option among a few, one value among many, a precise number, an approximate value, an item in a list.

JButton

Lab 1.1Lab 1.2all labs

Triggers an action. Disabled (greyed) while the action is not allowed.

JButton save = new JButton("Save");
save.addActionListener(e -> label.setText("Saved"));
save.setEnabled(false);                        // greyed: cannot be clicked yet

JCheckBox

Lab 2.1Lab 3.1

A yes / no option. Several check boxes can be ticked at the same time.

JCheckBox news = new JCheckBox("Receive the newsletter");
news.setSelected(true);                        // ticked at start
boolean wanted = news.isSelected();

JRadioButton + ButtonGroup

Lab 2.1Lab 3.1

One option among a few, all visible. The ButtonGroup makes them exclusive.

JRadioButton small = new JRadioButton("Small", true);   // selected at start
JRadioButton large = new JRadioButton("Large");
ButtonGroup size = new ButtonGroup();          // makes them exclusive (invisible)
size.add(small);
size.add(large);
JPanel sizes = new JPanel(new FlowLayout(FlowLayout.LEFT));
sizes.add(small);                              // still add them to a panel
sizes.add(large);
boolean isSmall = small.isSelected();

Both radio buttons can be ticked → they are not in the same ButtonGroup.

JComboBox

Lab 2.1Lab 3.1

One value among many; only the chosen value is visible, so it saves space.

JComboBox<String> city = new JComboBox<>(new String[]{"Algiers", "Oran", "Constantine"});
city.setSelectedIndex(0);
String chosen = city.getSelectedItem().toString();   // getSelectedItem() is an Object

JSpinner

Lab 2.1Lab 3.1

A precise number with arrows, inside limits.

JSpinner qty = new JSpinner(new SpinnerNumberModel(1, 1, 10, 1)); // value, min, max, step
int n = (Integer) qty.getValue();              // getValue() is an Object

A spinner has getValue(), not getText().

JSlider

Lab 2.1Lab 3.1

An approximate value in a range (a level, a rating).

JSlider level = new JSlider(0, 10, 5);         // min, max, value
level.setMajorTickSpacing(5);
level.setPaintTicks(true);
level.setPaintLabels(true);
int v = level.getValue();

JList

Lab 2.1Lab 3.2

Choose in a visible list of items.

JList<String> langs = new JList<>(new String[]{"Java", "Python", "C"});
langs.setSelectedIndex(1);
add(new JScrollPane(langs));                   // a list always goes in a JScrollPane
String pick = langs.getSelectedValue();        // null if nothing is selected

07Menus and the structure of a window

A main window has a menu bar, a work area and a status bar; a tool bar and tabs organise the work area.

JMenuBar, JMenu, JMenuItem

Lab 2.1Lab 3.1

The menu bar holds drop-down menus; each menu holds commands. A menu item reacts like a button.

JMenuBar menuBar = new JMenuBar();
JMenu file = new JMenu("File");
JMenuItem open = new JMenuItem("Open");
JMenuItem exit = new JMenuItem("Exit");
file.add(open);
file.addSeparator();                           // a line between groups of items
file.add(exit);
menuBar.add(file);
setJMenuBar(menuBar);                          // before setVisible(true)

exit.addActionListener(e -> System.exit(0));   // same event as a button
JMenuBarThe bar, attached with setJMenuBar.
JMenuA drop-down menu: File, Help…
JMenuItemA command: Open, Exit, About…
addSeparator()A line between groups of items.

Status bar

Lab 3.1

A JLabel at SOUTH that tells the user the state of the application ("Ready", "Saved").

Update it with setText after each important action: it is feedback.

08Events

A click on a button or a menu item produces an event. You attach the code to run with a listener.

1The user acts
2An event waits in a queue
3The listener runs
4The interface answers

ActionListener (lambda)

Lab 1.2all labs

The code executed at each click on a button, a menu item, a check box…

plus.addActionListener(e -> {
    count++;                                   // count is an attribute of the class
    label.setText("Total: " + count);          // update the screen
});

A local variable cannot be modified inside a lambda ("must be final or effectively final"): declare it as an attribute of the class.

Read the input in the listener

Lab 1.2Lab 3.1

Read the values at the moment of the click, not when the window is built.

go.addActionListener(e -> {
    String text = field.getText();             // read at the moment of the click
    label.setText("Hello " + text);
});

Enable a button only when it is allowed

Lab 2.1Lab 3.2

Error prevention: the user cannot do the action before the condition is met.

send.setEnabled(false);
accept.addActionListener(e -> send.setEnabled(accept.isSelected()));

WindowAdapter: the ✕ button

Lab 3.1

Run your own code when the user closes the window, for example to ask a confirmation.

setDefaultCloseOperation(JFrame.DO_NOTHING_ON_CLOSE);
addWindowListener(new WindowAdapter() {
    @Override
    public void windowClosing(WindowEvent e) {
        int answer = JOptionPane.showConfirmDialog(Notions.this, "Quit?", "Confirm",
                JOptionPane.YES_NO_OPTION);
        if (answer == JOptionPane.YES_OPTION) System.exit(0);
    }
});

Focus

Lab 3.2

After an error, put the cursor back where the user must correct.

field.requestFocus();                          // put the cursor back in the field

Events are processed one by one. A long task or Thread.sleep in a listener freezes the whole window: use javax.swing.Timer (chapter 11).

09Dialog boxes (JOptionPane)

A dialog box informs, warns, reports an error, asks a question or asks for a value. Choose the kind that matches the situation.

showMessageDialog

Lab 1.2Lab 2.1Lab 3.1Lab 3.2

Inform the user. The last parameter sets the icon: information, warning or error.

JOptionPane.showMessageDialog(this, "File saved.");          // information by default
JOptionPane.showMessageDialog(this, "Select an item first.", "Warning",
        JOptionPane.WARNING_MESSAGE);
JOptionPane.showMessageDialog(this, "The date must be dd/mm/yyyy.", "Error",
        JOptionPane.ERROR_MESSAGE);

An error message says what is wrong and how to fix it.

showConfirmDialog

Lab 3.1Lab 3.2

Ask a question before an important action (quit, delete).

int answer = JOptionPane.showConfirmDialog(this, "Delete this item?", "Confirm",
        JOptionPane.YES_NO_OPTION);
if (answer == JOptionPane.YES_OPTION) {
    // do the action
}

showInputDialog

Lab 3.2

Ask the user for one value.

String name = JOptionPane.showInputDialog(this, "Your name:");
if (name != null && !name.trim().isEmpty()) {  // null = Cancel
    label.setText(name);
}

10Lists, trees and tables

These components show data kept in a model. You change the model; the component refreshes itself.

DefaultListModel + JList

Lab 3.2

A list whose items can be added and removed while the program runs.

DefaultListModel<String> items = new DefaultListModel<>();
JList<String> list = new JList<>(items);
list.setSelectionMode(ListSelectionModel.SINGLE_SELECTION);

items.addElement("First item");                // the list shows it at once
int i = list.getSelectedIndex();               // -1 if nothing is selected
if (i >= 0) items.remove(i);

JTree + DefaultMutableTreeNode

Lab 3.2

Content with levels: categories and sub-categories, folders and files.

DefaultMutableTreeNode root = new DefaultMutableTreeNode("Root");
DefaultMutableTreeNode branch = new DefaultMutableTreeNode("Branch");
branch.add(new DefaultMutableTreeNode("Leaf 1"));
branch.add(new DefaultMutableTreeNode("Leaf 2"));
root.add(branch);
add(new JScrollPane(new JTree(root)));

Import javax.swing.tree.DefaultMutableTreeNode.

JTable + DefaultTableModel

Lab 2.1Lab 3.2

Data in rows and columns; rows added by the program, sorting by the user.

DefaultTableModel model = new DefaultTableModel(new String[]{"Name", "Age"}, 0);
JTable table = new JTable(model);
add(new JScrollPane(table));                   // needed to see the header
model.addRow(new Object[]{"Sara", 21});         // add a row
table.setAutoCreateRowSorter(true);            // click a header to sort
int row = table.getSelectedRow();              // -1 if no row is selected
if (row >= 0) {
    model.removeRow(table.convertRowIndexToModel(row));  // correct row even when sorted
}

No header on the table → put it in a JScrollPane. Import javax.swing.table.DefaultTableModel. Declare the model as an attribute if a listener uses it.

11Checking the input and giving feedback

Check the data before using it, and show the user that a long action is in progress.

Convert a text to a number

Lab 1.2

The text typed may not be a number: catch the error and explain.

try {
    int years = Integer.parseInt(age.getText().trim());
    label.setText("Age: " + years);
} catch (NumberFormatException ex) {
    JOptionPane.showMessageDialog(this, "Type a whole number, for example 20.",
            "Error", JOptionPane.ERROR_MESSAGE);
}

Check a value

Lab 3.2

Test the input first; on error, a message that says how to fix it, then the focus back in the field.

String mail = email.getText();
if (!mail.contains("@") || !mail.contains(".")) {
    JOptionPane.showMessageDialog(this, "The e-mail must contain @ and a dot.",
            "Error", JOptionPane.ERROR_MESSAGE);
    email.requestFocus();
    return;
}

Busy cursor and disabled button

Lab 3.2

During an action: no second click, and a cursor that shows the system is working.

save.setEnabled(false);                                        // no second click
setCursor(Cursor.getPredefinedCursor(Cursor.WAIT_CURSOR));     // busy
// ... when it is finished:
setCursor(Cursor.getDefaultCursor());
save.setEnabled(true);

JProgressBar + javax.swing.Timer

Lab 3.2

Show how far a long action is. The Timer runs its code at regular intervals without freezing the window.

JProgressBar bar = new JProgressBar(0, 100);
Timer timer = new Timer(100, null);            // javax.swing.Timer, every 100 ms
timer.addActionListener(e -> {
    bar.setValue(bar.getValue() + 10);
    if (bar.getValue() >= 100) timer.stop();
});
timer.start();

Use javax.swing.Timer, not Thread.sleep: sleep freezes the interface.
