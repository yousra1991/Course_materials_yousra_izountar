Interactive manual · Lab 2.2

This manual follows Lab 2.2 step by step, with the same statements, expected interfaces and guidelines as the lab. You read the statement and see the expected interface, then you run the code line by line (or component by component): the window on the left is built together with the code on the right, and the line matching each component is highlighted. The code is locked until you reach the exercise: understand it, then write it yourself.

Objectives

By the end of this manual you will be able to:
  • Audit an interface and identify its ergonomic errors, naming the principle or heuristic each one violates.
  • Correct an interface: no absolute positioning, grouped fields, readable labels, big buttons, default button, confirmation and clear messages.
  • Apply similarity, proximity, Fitts's law and Hick's law to design a kiosk screen.
  • Give visible feedback during a wait with JProgressBar and javax.swing.Timer (2-second rule).
