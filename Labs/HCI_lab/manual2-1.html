Interactive manual · Lab 2.1

This manual follows Lab 2.1 step by step, with the same statements, expected interfaces and guidelines as the lab. You read the statement and see the expected interface, then you run the code line by line (or component by component): the window on the left is built together with the code on the right, and the line matching each component is highlighted. The code is locked until you reach the exercise: understand it, then write it yourself.

Objectives

By the end of this manual you will be able to:
  • Set up the project TpSwing2 with one class per exercise.
  • Use text and selection components: JTextField, JPasswordField, JComboBox, JSpinner, radio buttons, check boxes, JList, JSlider and JTextArea.
  • Organize a form with JTabbedPane and GridLayout.
  • Add a menu bar, buttons with events, and a JTable updated by the form.
🔒 The code on the right cannot be selected or copied until you reach the exercise at the end of this manual. Read the statement, look at the expected interface, understand the code, then write it yourself in the lab.
