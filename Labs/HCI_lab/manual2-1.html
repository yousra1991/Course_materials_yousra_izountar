This manual follows Lab 2.1 step by step, with the same statements, expected interfaces and guidelines as the lab. On the left you read the statement and see the interface to build; on the right you see the code that produces it. Objectives

By the end of this manual you will be able to:
  • Set up the project TpSwing2 with one class per exercise.
  • Use text and selection components: JTextField, JPasswordField, JComboBox, JSpinner, radio buttons, check boxes, JList, JSlider and JTextArea.
  • Organize a form with JTabbedPane and GridLayout.
  • Add a menu bar, buttons with events, and a JTable updated by the form.
