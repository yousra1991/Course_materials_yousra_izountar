Installation & First Collection

Create your Atlas account, deploy a free cluster, install mongosh, connect, then create the univ database and the students collection.

For each exercise, the expected result and guidelines are provided, from 🟢 simple to 🔴 difficult: write the commands yourself in mongosh. Start the commands of every exercise with use univ and add // comments. Your results must match the expected results (same data, same field names).
