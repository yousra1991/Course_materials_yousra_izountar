Lab 1 – Installation & first collection

0.1–0.3 · Atlas account, M0 cluster, database user, network access
No command here. Checkpoints: the e-mail address is verified; the cluster Cluster0 (M0 Free) shows as running; a database user student with the role Read and write to any database exists; the network access list contains 0.0.0.0/0.
0.4 · Install mongosh
Commands
mongosh --version
Expected result
a version number, for example 2.x.x
0.5 · Connect to your cluster
Commands
# In the terminal (copy the exact command from Atlas):
mongosh "mongodb+srv://cluster0.xxxxx.mongodb.net/" --apiVersion 1 --username student

// Then, inside mongosh:
db.runCommand({ ping: 1 })
Expected result
{ ok: 1 }
Replace cluster0.xxxxx by the address given by Atlas (button Connect → Shell).

Lab 2 – CRUD operations

2.1 · Insert one document (insertOne)
Commands
// Select the database
use univ
// Insert the first student
db.students.insertOne({
  name: "Amine", age: 22, city: "Alger", speciality: "ASD",
  average: 14.5, modules: ["NoSQL", "BI"], scholarship: true
})
// Display the collection to check
db.students.find()
Expected result
{ acknowledged: true, insertedId: ObjectId('...') }
2.2 · Insert many documents (insertMany)
Commands
// Select the database
use univ
// Insert the 7 other students in one call (an array of documents)
db.students.insertMany([
  { name: "Yasmine", age: 23, city: "Oran",        speciality: "ASD", average: 16.2, modules: ["NoSQL", "ML", "BI"] },
  { name: "Karim",   age: 24, city: "Constantine", speciality: "SIC", average: 11.8, modules: ["Web"] },
  { name: "Lina",    age: 22, city: "Alger",       speciality: "ASD", average: 17.1, modules: ["NoSQL", "ML"], scholarship: true },
  { name: "Samir",   age: 25, city: "Annaba",      speciality: "SIC", average: 9.5,  modules: ["Web", "NoSQL"] },
  { name: "Nadia",   age: 23, city: "Oran",        speciality: "ASD", average: 13.0, modules: ["BI"], scholarship: false },
  { name: "Walid",   age: 26, city: "Blida",       speciality: "SIC", average: 8.7,  modules: [] },
  { name: "Sarah",   age: 22, city: "Alger",       speciality: "ASD", average: 15.4, modules: ["NoSQL", "ML", "BI"], scholarship: true }
])
// Count the students
db.students.countDocuments()
Expected result
{ acknowledged: true, insertedIds: { '0': ObjectId('...'), ..., '6': ObjectId('...') } }
8
Fields marked with a dash in the table (Yasmine, Karim, Samir, Walid have no scholarship) are simply left out.
3.1 · Read documents: find() and findOne()
Commands
// Select the database
use univ
// (a) all the students
db.students.find()
// (b) their number
db.students.countDocuments()
// (c) the first student found
db.students.findOne()
// (d) the students living in Alger
db.students.find({ city: "Alger" })
// (e) the student named Yasmine
db.students.findOne({ name: "Yasmine" })
Expected result
(b) 8
(d) Amine, Lina, Sarah (3 documents)
(e) { name: 'Yasmine', age: 23, city: 'Oran', ... }
3.2 · Filter, project, sort and limit
Commands
// Select the database
use univ
// (a) ASD students living in Alger: name and average, without _id
db.students.find({ speciality: "ASD", city: "Alger" }, { name: 1, average: 1, _id: 0 })
// (b) all the students, best average first
db.students.find({}, { name: 1, average: 1, _id: 0 }).sort({ average: -1 })
// (c) the 3 best students
db.students.find({}, { name: 1, average: 1, _id: 0 }).sort({ average: -1 }).limit(3)
// (d) the distinct cities
db.students.distinct("city")
Expected result
(a) Amine 14.5, Lina 17.1, Sarah 15.4
(c) Lina 17.1, Yasmine 16.2, Sarah 15.4
(d) [ 'Alger', 'Annaba', 'Blida', 'Constantine', 'Oran' ]
4.1 · Update one document (updateOne and $set)
Commands
// Select the database
use univ
// (a) Karim moves to Alger
db.students.updateOne({ name: "Karim" }, { $set: { city: "Alger" } })
// (b) add the new field level to Amine
db.students.updateOne({ name: "Amine" }, { $set: { level: "M2" } })
// (c) check both students
db.students.find({ name: { $in: ["Karim", "Amine"] } })
Expected result
matchedCount: 1, modifiedCount: 1 (for (a) and for (b))
4.2 · Update many documents ($inc, updateMany, upsert)
Commands
// Select the database
use univ
// (a) +0.5 on the average of every ASD student
db.students.updateMany({ speciality: "ASD" }, { $inc: { average: 0.5 } })
// (b) every student gets the field status
db.students.updateMany({}, { $set: { status: "active" } })
// (c) upsert: update Rayan, or create him if he does not exist
db.students.updateOne(
  { name: "Rayan" },
  { $set: { age: 24, city: "Setif", speciality: "SIC", average: 12 } },
  { upsert: true }
)
// (d) name and average of the ASD students
db.students.find({ speciality: "ASD" }, { name: 1, average: 1, _id: 0 })
Expected result
(a) matchedCount: 5, modifiedCount: 5
(b) matchedCount: 8, modifiedCount: 8
(c) matchedCount: 0, modifiedCount: 0, upsertedCount: 1, upsertedId: ObjectId('...')
(d) Amine 15, Yasmine 16.7, Lina 17.6, Nadia 13.5, Sarah 15.9
5.1 · Delete documents (deleteOne and deleteMany)
Commands
// Select the database
use univ
// (a) delete Rayan
db.students.deleteOne({ name: "Rayan" })
// (b) delete all the students living in Annaba
db.students.deleteMany({ city: "Annaba" })
// (c) delete the SIC students living in Blida
db.students.deleteMany({ speciality: "SIC", city: "Blida" })
// (d) count the remaining students
db.students.countDocuments()
Expected result
(a) deletedCount: 1
(b) deletedCount: 1
(c) deletedCount: 1
(d) 6
Never run deleteMany({}): it deletes every document.

Lab 3 – Query operators & final challenge

6.1 · Comparison and logical operators
Commands
use("univ")
db.students.drop()
db.students.insertMany([
  { name: "Amine",   age: 22, city: "Alger",       speciality: "ASD", average: 14.5, modules: ["NoSQL", "BI"],       scholarship: true },
  { name: "Yasmine", age: 23, city: "Oran",        speciality: "ASD", average: 16.2, modules: ["NoSQL", "ML", "BI"] },
  { name: "Karim",   age: 24, city: "Constantine", speciality: "SIC", average: 11.8, modules: ["Web"] },
  { name: "Lina",    age: 22, city: "Alger",       speciality: "ASD", average: 17.1, modules: ["NoSQL", "ML"],       scholarship: true },
  { name: "Samir",   age: 25, city: "Annaba",      speciality: "SIC", average: 9.5,  modules: ["Web", "NoSQL"] },
  { name: "Nadia",   age: 23, city: "Oran",        speciality: "ASD", average: 13.0, modules: ["BI"],                scholarship: false },
  { name: "Walid",   age: 26, city: "Blida",       speciality: "SIC", average: 8.7,  modules: [] },
  { name: "Sarah",   age: 22, city: "Alger",       speciality: "ASD", average: 15.4, modules: ["NoSQL", "ML", "BI"], scholarship: true }
])

// (a) average >= 15
db.students.find({ average: { $gte: 15 } }, { name: 1, _id: 0 })
// (b) age from 23 to 25 inclusive (one condition, two operators)
db.students.find({ age: { $gte: 23, $lte: 25 } }, { name: 1, _id: 0 })
// (c) living in Oran or Annaba
db.students.find({ city: { $in: ["Oran", "Annaba"] } }, { name: 1, _id: 0 })
// (d) ASD students with an average below 15
db.students.find({ speciality: "ASD", average: { $lt: 15 } }, { name: 1, _id: 0 })
// (e) average below 10 or above 17
db.students.find({ $or: [ { average: { $lt: 10 } }, { average: { $gt: 17 } } ] }, { name: 1, _id: 0 })
Expected result
(a) Yasmine, Lina, Sarah → 3
(b) Yasmine, Karim, Samir, Nadia → 4
(c) Yasmine, Samir, Nadia → 3
(d) Amine, Nadia → 2
(e) Lina, Samir, Walid → 3
6.2 · Array, element and evaluation operators
Commands
// Select the database (same 8 students as 6.1)
use univ
// (a) students who follow NoSQL
db.students.find({ modules: "NoSQL" }, { name: 1, _id: 0 })
// (b) students who follow both NoSQL and ML
db.students.find({ modules: { $all: ["NoSQL", "ML"] } }, { name: 1, _id: 0 })
// (c) name starts with S
db.students.find({ name: { $regex: "^S" } }, { name: 1, _id: 0 })
// (d) students having a scholarship field (even false)
db.students.find({ scholarship: { $exists: true } }, { name: 1, _id: 0 })
// (e) students without that field
db.students.find({ scholarship: { $exists: false } }, { name: 1, _id: 0 })
// (f) students who follow NoSQL but not ML
db.students.find({ modules: { $in: ["NoSQL"], $nin: ["ML"] } }, { name: 1, _id: 0 })
Expected result
(a) Amine, Yasmine, Lina, Samir, Sarah → 5
(b) Yasmine, Lina, Sarah → 3
(c) Samir, Sarah → 2
(d) Amine, Lina, Nadia, Sarah → 4
(e) Yasmine, Karim, Samir, Walid → 4
(f) Amine, Samir → 2
7.1 · Challenge: prepare the jury
Commands
// Select the database (same 8 students, untouched)
use univ
// 1. the field mention, one updateMany per range
db.students.updateMany({ average: { $gte: 16 } }, { $set: { mention: "Very Good" } })
db.students.updateMany({ average: { $gte: 14, $lt: 16 } }, { $set: { mention: "Good" } })
db.students.updateMany({ average: { $gte: 12, $lt: 14 } }, { $set: { mention: "Fair" } })
// 2. ASD students who follow NoSQL with the mention Very Good or Good
db.students.find(
  { speciality: "ASD", modules: "NoSQL", mention: { $in: ["Very Good", "Good"] } },
  { name: 1, mention: 1, _id: 0 }
)
// 3. students enrolled in 3 modules or more
db.students.find({ $expr: { $gte: [ { $size: "$modules" }, 3 ] } }, { name: 1, _id: 0 })
// 4. delete the students without any mention, then list the others
db.students.deleteMany({ mention: { $exists: false } })
db.students.find({}, { name: 1, mention: 1, _id: 0 }).sort({ average: -1 })
Expected result
1. matchedCount: 2 (Very Good), 2 (Good), 1 (Fair)
2. Amine (Good), Yasmine (Very Good), Lina (Very Good), Sarah (Good) → 4
3. Yasmine, Sarah → 2
4. deletedCount: 3 (Karim, Samir, Walid)
   Lina (Very Good), Yasmine (Very Good), Sarah (Good), Amine (Good), Nadia (Fair)
For question 3, db.students.find({ "modules.2": { $exists: true } }) gives the same result.
