db.students.find({ city: { $in: ["Oran", "Annaba"] } })
A. { $and: [{ city: "Oran" }, { city: "Annaba" }] }A. { $and: [{ city: "Oran" }, { city: "Annaba" }] }
B. { city: { $nin: ["Oran", "Annaba"] } }B. { city: { $nin: ["Oran", "Annaba"] } }
C. { $or: [{ city: "Oran" }, { city: "Annaba" }] }  ✔C. { $or: [{ city: "Oran" }, { city: "Annaba" }] }  ✔
D. { city: ["Oran", "Annaba"] }D. { city: ["Oran", "Annaba"] }
Explanation:Explication : $in with a list of values is equivalent to $or on the same field. A matches nobody (no city is both Oran and Annaba), B is the opposite ($nin), D compares the city with a whole array and matches nothing.$in avec une liste de valeurs équivaut à $or sur le même champ. A ne renvoie personne (aucune ville n'est à la fois Oran et Annaba), B est l'inverse ($nin), D compare la ville à un tableau entier et ne correspond à rien.
