Question 1 — answer B

How many documents does this query return?

db.students.find({ average: { $gte: 15 } })
A. 2
B. 3  ✔
C. 4
D. 5
Explanation: Yasmine (16.2), Lina (17.1) and Sarah (15.4): 3 documents. Amine has 14.5, so he is not included ($gte: greater than or equal).

Question 2 — answer C

Which query returns the students living in Oran or Annaba?

A. db.students.find({ city: "Oran", city: "Annaba" })
B. db.students.find({ $and: [ { city: "Oran" }, { city: "Annaba" } ] })
C. db.students.find({ city: { $in: ["Oran", "Annaba"] } })  ✔
D. db.students.find({ city: { $and: ["Oran", "Annaba"] } })
Explanation: $in accepts any of the listed values. A: the key city is written twice, the second one replaces the first, so only Annaba is searched. B: nobody lives in both cities, the result is empty. D: $and is not a field operator, MongoDB reports an error.

Question 3 — answer A

What does this query display?

db.students.find(
  { speciality: "ASD", average: { $lt: 15 } },
  { name: 1, _id: 0 }
)
A. Amine and Nadia  ✔
B. Amine, Yasmine and Nadia
C. Nadia only
D. Karim, Samir and Walid
Explanation: Two fields in the same filter mean AND. The ASD students are Amine (14.5), Yasmine (16.2), Lina (17.1), Nadia (13.0) and Sarah (15.4); only Amine and Nadia are below 15. The projection keeps the name and hides the _id. Karim, Samir and Walid are SIC students.

Question 4 — answer C

Which students does this query return?

db.students.find({
  $or: [ { average: { $lt: 10 } }, { average: { $gt: 17 } } ]
})
A. Lina only
B. Samir and Walid
C. Lina, Samir and Walid  ✔
D. Lina, Samir, Walid and Karim
Explanation: Samir has 9.5, Walid 8.7 (both below 10) and Lina 17.1 (above 17). Karim has 11.8: he matches neither condition.

Question 5 — answer A

Which students does this query return?

db.students.find({ modules: { $all: ["NoSQL", "ML"] } })
A. Yasmine, Lina and Sarah  ✔
B. Amine, Yasmine, Lina, Samir and Sarah
C. Yasmine and Lina
D. Lina only
Explanation: $all requires every listed value in the array: Yasmine [NoSQL, ML, BI], Lina [NoSQL, ML] and Sarah [NoSQL, ML, BI]. Option B lists all the students who follow NoSQL, whether or not they follow ML.

Question 6 — answer B

What does this query return?

db.students.countDocuments({ scholarship: { $exists: true } })
A. 3
B. 4  ✔
C. 5
D. 8
Explanation: $exists: true tests the presence of the field, not its value. Amine, Lina and Sarah have true and Nadia has false: the field exists for these 4 students.

Question 7 — answer A

Which students does this query return?

db.students.find({ modules: { $in: ["NoSQL"], $nin: ["ML"] } })
A. Amine and Samir  ✔
B. Amine, Yasmine, Lina, Samir and Sarah
C. Yasmine, Lina and Sarah
D. Amine only
Explanation: The students who follow NoSQL are Amine, Yasmine, Lina, Samir and Sarah; among them, Yasmine, Lina and Sarah also follow ML and are excluded by $nin. Remaining: Amine [NoSQL, BI] and Samir [Web, NoSQL].

Question 8 — answer C

A student wants the students aged 23 to 25 inclusive and writes this query. How many documents does it really return?

db.students.countDocuments({
  age: { $gte: 23 },
  age: { $lte: 25 }
})
A. 4
B. 5
C. 7  ✔
D. 8
Explanation: The key age appears twice: the second condition replaces the first, so the query is only age <= 25. Everybody except Walid (26) matches: 7 documents. The right query is { age: { $gte: 23, $lte: 25 } }, which returns 4.

Question 9 — answer B

The 8 students are untouched. What is matchedCount of this command?

db.students.updateMany(

A. 0
B. 1  ✔

D. 3
Explanation: Only Nadia (13.0) has an average from 12 (included) to 14 (excluded). Karim has 11.8, which is below 12.

Question 10 — answer C

Each student with an average of 12 or more now has a mention field (Very Good, Good or Fair). What is deletedCount?

db.students.deleteMany({ mention: { $exists: false } })
A. 1
B. 2
C. 3  ✔
D. 5
Explanation: The students below 12 have no mention: Karim (11.8), Samir (9.5) and Walid (8.7), i.e. 3 documents. The 5 others (Lina, Yasmine, Sarah, Amine, Nadia) have one.
